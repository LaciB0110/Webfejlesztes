# Recepttár Nyilvántartó (Python Flask + SQLite + JWT)

Ez a projekt egy letisztult Recept és Kategória (1:N reláció) nyilvántartó webalkalmazás, amely a gyökér útvonalon magát a frontendet szolgálja ki.

## Indítás lépései:

1. Lépj be a backend mappába:
```bash
cd backend
```

2. Telepítsd a szükséges csomagokat:
```bash
pip install flask flask-cors flask-sqlalchemy pyjwt
```

3. Indítsd el a Python backend szervert:
```bash
python app.py
```

4. Nyisd meg a böngészőt a megadott címen:
[http://127.0.0.1:5000](http://127.0.0.1:5000)
